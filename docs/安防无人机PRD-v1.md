## 1. 产品概述

### 1.1 产品定位
基于 **OpenHD 无线电链路 + MAVLink 协议** 的轻量级安防无人机云平台，提供**不依赖 4G/5G** 的实时监控、远程控制、任务管理与日志分析能力。

### 1.2 核心价值主张
| 价值点 | 说明 | 竞品对比 |
|--------|------|----------|
| **不依赖公网** | OpenHD 无线电链路，适合偏远/应急场景 | 大疆司空 2 强依赖 4G/5G |
| **开放协议** | MAVLink 标准协议，兼容 PX4/ArduPilot | 大疆封闭生态 |
| **轻量部署** | Docker Compose 一键启动，单台服务器可跑 | 道通需专用服务器 |
| **AI 辅助运维** | RAG 日志分析，降低故障排查门槛 | 竞品无此功能 |

### 1.3 目标用户
| 角色 | 核心诉求 | 使用场景 | 优先级 |
|------|----------|----------|--------|
| 安保人员 | 实时视频、设备状态、一键报警 | 夜间巡逻、火情监控 | P0 |
| 运维工程师 | 设备健康、日志回放、参数调优 | 故障排查、固件升级 | P0 |
| 指挥官 | 全局态势、多机协同、任务调度 | 应急响应、大型活动保障 | P1 |

## 2. 核心功能 (MVP)

### 2.1 监控大屏
| 功能 | 验收标准 | 异常处理 |
|------|----------|----------|
| **实时地图** | 显示无人机位置、飞行轨迹、禁飞区；位置更新频率 ≥ 1Hz | GPS 信号丢失时显示最后已知位置 + 警告图标 |
| **视频流** | H.264 解码，延迟 < 800ms，支持全屏 | 视频流断开时显示"信号丢失"占位图 |
| **状态面板** | 电量、高度、速度、信号强度、GPS 星数，1s 刷新 | 数据超时 3s 未更新标红，5s 标灰 |
| **告警面板** | 低电量 (<20%)、信号丢失、越界告警实时弹窗 | 告警需手动确认，未确认告警持续闪烁 |

### 2.2 设备管理
| 功能 | 验收标准 | 异常处理 |
|------|----------|----------|
| **设备列表** | 在线/离线状态、基本信息、最后心跳时间 | 离线超过 5 分钟标记为"失联" |
| **设备详情** | 详细参数、历史任务、日志记录 | 无历史数据时显示空状态引导 |
| **远程控制** | 一键起飞、返航、降落、云台控制 | 指令下发后 3s 未收到 ACK 提示"发送失败" |

### 2.3 任务管理
| 功能 | 验收标准 | 异常处理 |
|------|----------|----------|
| **航线规划** | 地图打点生成矩形/多边形航线，支持高度/速度设置 | 航点超出飞控能力范围时提示"航线无效" |
| **任务执行** | 下发任务、监控进度、暂停/恢复 | 任务执行中失联自动触发返航 |
| **任务报告** | 飞行时长、覆盖面积、异常事件统计 | 数据缺失时标注"部分数据不可用" |

### 2.4 日志与回放
| 功能 | 验收标准 | 异常处理 |
|------|----------|----------|
| **日志上传** | 支持 .bin/.tlog 格式，自动解析 | 格式不支持提示"请上传 MAVLink 日志" |
| **数据回放** | 轨迹回放、参数曲线、播放速度 0.5x-4x | 日志损坏提示"文件解析失败" |
| **异常分析** | AI 辅助诊断飞行异常原因 (RAG) | 无法诊断时返回"建议人工排查" |

## 3. User Story (深化版)

### US-01: 实时视频监控
```
作为安保人员
我希望在 Web 端看到实时视频流
以便确认火情或异常事件

验收标准:
  Given 无人机已起飞且视频流正常
  When 我打开监控大屏
  Then 视频流应在 3s 内加载完成
  And 延迟应 < 800ms
  And 支持一键全屏

异常场景:
  When 视频流中断
  Then 显示"信号丢失"占位图
  And 提示"正在重连..."
  And 30s 后仍未恢复则弹窗告警
```

### US-02: 低电量告警
```
作为安保人员
我希望收到低电量告警
以便提前安排返航

验收标准:
  Given 无人机正在执行任务
  When 电量降至 20% 以下
  Then 告警面板显示红色告警
  And 播放告警音 (可关闭)
  And 地图标记闪烁

异常场景:
  When 用户未确认告警
  Then 告警持续闪烁
  And 电量降至 10% 时自动触发返航 (需配置)
```

### US-03: 飞行日志下载与回放
```
作为运维工程师
我希望下载飞行日志并回放
以便排查故障或优化航线

验收标准:
  Given 任务已完成
  When 我进入任务详情页
  Then 可下载 .bin/.tlog 日志文件
  And 可在 Web 端直接回放
  And 回放支持暂停/快进/慢放

异常场景:
  When 日志文件损坏
  Then 提示"文件解析失败，请重新下载"
  And 提供联系支持的入口
```

### US-04: 一键返航
```
作为指挥官
我希望一键下发返航指令
以便紧急回收无人机

验收标准:
  Given 无人机正在执行任务
  When 我点击"一键返航"
  Then 弹出二次确认框
  And 确认后指令 3s 内下发
  And 收到 ACK 后显示"返航指令已执行"

异常场景:
  When 指令下发后 3s 未收到 ACK
  Then 提示"发送失败，请重试"
  And 记录失败日志
```

### US-05: 实时位置追踪
```
作为安保人员
我希望在地图上看到无人机实时位置
以便掌握飞行态势

验收标准:
  Given 无人机 GPS 信号正常
  When 我打开监控大屏
  Then 地图上显示无人机图标
  And 位置更新频率 ≥ 1Hz
  And 显示飞行轨迹线

异常场景:
  When GPS 信号丢失
  Then 显示最后已知位置 + 警告图标
  And 提示"GPS 信号弱"
  And 位置更新频率降至 0.1Hz
```

## 4. 非功能性需求

| 维度 | 要求 | 测试方法 |
|------|------|----------|
| **性能** | 遥测数据端到端延迟 < 200ms | 压测工具模拟 50 架无人机 |
| **可用性** | 7×24 小时运行，MTBF > 1000h | 长时间稳定性测试 |
| **安全性** | JWT 鉴权，HTTPS/WSS 加密 | 渗透测试 + 代码审计 |
| **兼容性** | Chrome/Edge/Safari 最新两版本 | 跨浏览器自动化测试 |
| **离线能力** | 断网 10 分钟数据不丢失 | 断网重连测试 |

## 5. 数据流向 (详细版)

```
┌─────────────┐     MAVLink      ┌──────────────────┐
│  无人机飞控  │ ────────────────→ │ OpenHD 天空端    │
│  (PX4/AP)   │                  │ (无线电发射)     │
└─────────────┘                  └────────┬─────────┘
                                          │ 无线电链路
                                          ↓
┌─────────────┐     UDP/MQTT     ┌──────────────────┐
│  Web 前端   │ ←── WebSocket ─── │ 云端接入服务     │
│  (React)    │                  │ (Go + EMQX)      │
└─────────────┘                  └────────┬─────────┘
                                          │
                                          ↓
                                ┌──────────────────┐
                                │ 数据存储层       │
                                │ MySQL + Redis    │
                                └──────────────────┘
```

### 5.1 关键消息流
| 消息类型 | 方向 | 频率 | 协议 |
|----------|------|------|------|
| HEARTBEAT | 飞控 → 云端 | 1Hz | MAVLink |
| GLOBAL_POSITION_INT | 飞控 → 云端 | 5Hz | MAVLink |
| ATTITUDE | 飞控 → 云端 | 10Hz | MAVLink |
| COMMAND_LONG | 云端 → 飞控 | 按需 | MAVLink |
| VIDEO_STREAM | 天空端 → 地面端 | 30fps | OpenHD |
| TELEMETRY | 云端 → 前端 | 1Hz | WebSocket |

## 6. 技术栈 (MVP)

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| **前端** | React 18 + TypeScript + Tailwind CSS + Vite | 组件化开发，暗色主题 |
| **图表** | ECharts / Recharts | 实时遥测曲线 |
| **地图** | Leaflet / Mapbox | 开源方案，支持离线瓦片 |
| **后端** | Go 1.21 + Gin + GORM + Swagger | 高性能，易部署 |
| **消息** | EMQX 5.x (MQTT) + Gorilla WebSocket | 实时推送 |
| **数据库** | MySQL 8.0 + Redis 7.x | 结构化数据 + 缓存 |
| **部署** | Docker Compose | 一键启动开发环境 |

## 7. API 接口草案 (v1)

### 7.1 设备管理
| 方法 | 路径 | 说明 | 请求体 | 响应 |
|------|------|------|--------|------|
| GET | `/api/v1/devices` | 获取设备列表 | - | `Device[]` |
| GET | `/api/v1/devices/{id}` | 获取设备详情 | - | `Device` |
| POST | `/api/v1/devices/{id}/command` | 下发指令 | `CommandRequest` | `CommandResponse` |
| GET | `/api/v1/devices/{id}/telemetry` | 获取实时遥测 | - | `Telemetry` |

### 7.2 任务管理
| 方法 | 路径 | 说明 | 请求体 | 响应 |
|------|------|------|--------|------|
| POST | `/api/v1/tasks` | 创建任务 | `TaskCreate` | `Task` |
| GET | `/api/v1/tasks/{id}` | 获取任务详情 | - | `Task` |
| POST | `/api/v1/tasks/{id}/execute` | 执行任务 | - | `TaskStatus` |
| POST | `/api/v1/tasks/{id}/pause` | 暂停任务 | - | `TaskStatus` |

### 7.3 日志管理
| 方法 | 路径 | 说明 | 请求体 | 响应 |
|------|------|------|--------|------|
| POST | `/api/v1/logs/upload` | 上传日志 | `multipart/form-data` | `LogMeta` |
| GET | `/api/v1/logs/{id}` | 获取日志详情 | - | `LogDetail` |
| GET | `/api/v1/logs/{id}/playback` | 获取回放数据 | - | `PlaybackStream` |
