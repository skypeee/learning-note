# 安防无人机云平台 - 竞品分析报告

> **日期**: 2026-04-21
> **分析维度**: 产品定位、核心功能、技术架构、用户体验、商业模式
> **竞品选择**: 大疆司空 2、道通智能云平台、极飞农业云（参考调度逻辑）

## 1. 大疆司空 2 (DJI FlightHub 2)

### 1.1 产品定位
- **目标用户**: 公共安全、能源巡检、环保监测
- **核心价值**: "云端 + 边端"协同，支持大疆全系行业无人机
- **定价**: SaaS 订阅制（基础版免费，高级版 ¥9,999/年）

### 1.2 核心功能
| 功能 | 实现方式 | 亮点 |
|------|----------|------|
| **实时监控** | 4G/5G 图传，延迟 200-500ms | 支持多机同屏，画中画切换 |
| **航线规划** | 3D 地图打点，自动生成航线 | 支持建图航拍、倾斜摄影 |
| **AI 识别** | 云端 AI 分析视频流 | 人/车/火点/安全帽检测 |
| **直播推流** | RTMP/GB28181 协议 | 一键推流到指挥中心大屏 |
| **设备管理** | 固件升级、电池管理、维修记录 | 电池循环次数追踪 |

### 1.3 技术架构 (推测)
```
无人机 → DJI O3/O4 图传 → 遥控器 → 4G/5G → 云端
                                            ↓
                                    视频转码服务
                                    AI 推理服务
                                    数据存储 (时序数据库)
                                            ↓
                                    Web 控制台 + 移动 App
```

### 1.4 优缺点分析
| ✅ 优势 | ❌ 劣势 |
|---------|---------|
| 生态闭环，软硬件深度优化 | 仅支持大疆自家无人机（封闭生态） |
| AI 识别准确率高（行业标杆） | 订阅费用高，中小企业负担重 |
| 多机协同能力强 | 依赖 4G/5G 网络，无网区域不可用 |
| 支持第三方平台接入 (API 开放) | 定制化能力弱，无法私有化部署 |

## 2. 道通智能云平台 (Autel SkyLink)

### 2.1 产品定位
- **目标用户**: 警用安防、消防应急、测绘
- **核心价值**: "开放 + 轻量"，支持多品牌无人机接入
- **定价**: 项目制报价（私有化部署 ¥50,000 起）

### 2.2 核心功能
| 功能 | 实现方式 | 亮点 |
|------|----------|------|
| **多机接入** | 支持 MAVLink 协议，兼容开源飞控 | 可接大疆 + 自组网无人机 |
| **网格巡检** | 自动划分巡检区域，多机分配 | 适合大面积安防巡逻 |
| **夜视增强** | 红外 + 可见光融合显示 | 夜间热源识别 |
| **离线模式** | 断网后本地缓存，联网后同步 | 适合无网/弱网环境 |
| **指挥调度** | 多角色权限，任务分配 | 适合应急指挥中心 |

### 2.3 技术架构 (推测)
```
无人机 → MAVLink → 地面站/网关 → MQTT/HTTP → 云端
                                          ↓
                                    协议适配层
                                    任务调度引擎
                                    时序数据库 (InfluxDB)
                                          ↓
                                    Web 控制台 + 大屏
```

### 2.4 优缺点分析
| ✅ 优势 | ❌ 劣势 |
|---------|---------|
| 开放协议，兼容多品牌 | AI 能力弱于大疆 |
| 支持私有化部署 | 生态不如大疆完善 |
| 离线模式适合野外场景 | UI/UX 体验一般 |
| 项目制定制灵活 | 文档和社区支持少 |

## 3. 极飞农业云 (XAG Agricultural Cloud)

### 3.1 为什么参考极飞？
虽然极飞主打农业，但其**多机调度逻辑**和**任务闭环设计**对安防场景有极高参考价值。

### 3.2 可借鉴的亮点
| 功能 | 安防场景的映射 |
|------|----------------|
| **地块划分 → 巡检区域划分** | 把厂区/园区划分为多个巡检网格 |
| **作业报告 → 巡检报告** | 自动生成覆盖率、异常点统计 |
| **农机管理 → 无人机管理** | 设备健康度、电池寿命预测 |
| **农情分析 → 安防态势分析** | 基于历史数据预测风险热点 |

## 5. 我们的差异化策略

### 5.1 核心优势
1. **OpenHD 无线电链路**：不依赖 4G/5G，适合偏远地区/应急场景
2. **MAVLink 开放协议**：兼容 PX4/ArduPilot，不绑定单一硬件
3. **轻量级架构**：Docker 一键部署，中小企业可自建
4. **AI 日志分析**：用 RAG 做飞行异常诊断，降低运维门槛

### 5.2 MVP 聚焦
- ✅ **必须做**：实时监控、设备管理、基础航线、日志回放
- ❌ **MVP 不做**：多机协同、AI 视频识别、3D 建模、直播推流

### 5.3 技术护城河
- **OpenHD + MAVLink 桥接**：市面少见，技术门槛高
- **轻量化部署**：Docker Compose 一键跑，比大疆/道通轻 10 倍
- **可扩展架构**：后续可加 AI 模块、多机协同模块

## 6. 对我们的 PRD 的启示

### 6.1 必须补充的功能
1. **离线缓存机制**：断网时数据本地保存，联网后自动同步
2. **多协议适配层**：未来可能接大疆 SDK，预留接口
3. **设备健康度评分**：电池循环、电机振动、传感器校准状态
4. **简易航线规划**：MVP 阶段先做矩形/多边形区域，不做 3D

### 6.2 可以砍掉的功能 (MVP 阶段)
1. ~~AI 视频实时识别~~（算力要求高，留到 V2）
2. ~~多机协同调度~~（逻辑复杂，留到 V2）
3. ~~3D 地图建模~~（非核心需求）
4. ~~直播推流到第三方平台~~（安防场景优先级低）
