# 间隔复习追踪

> 规则：学完一个知识点后，按 1d → 3d → 7d → 15d 间隔复习
> 每次复习后标记 ✅，全部复习完标记为"已掌握"
> 说"继续学习"时，AI 会检查到期需要复习的知识点

## 复习间隔定义

| 复习轮次 | 间隔 | 说明 |
|---------|------|------|
| R1 | 1 天后 | 第一次回忆，巩固短期记忆 |
| R2 | 3 天后 | 第二次回忆，加深理解 |
| R3 | 7 天后 | 第三次回忆，转入长期记忆 |
| R4 | 15 天后 | 第四次回忆，确认已掌握 |
