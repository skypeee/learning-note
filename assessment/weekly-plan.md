# 每周学习计划

> 排期范围：滚动 2 周，做完再排下一周
> 使用方式：说"继续学习"或"有时间了"，AI 从任务池列出待领取任务

## 固定节奏

| 场景 | 内容 | 时长 |
|------|------|------|
| 白天工作 | A 维度（有板就测）> B 维度（产品思考）> C 维度（开发） | 按需 |
| 等 vibecoding/等板子 | 产品设计/RN 学习/飞控储备（碎片自由分配） | 5-15min × N 段 |
| 晚上娃睡后 | 深度开发（RN 迁移 + 后端基础设施） | 30-60min |
| 周末（选半天） | 大块任务（架构迁移/PRD 场景写透/实验验证） | 1.5-2h |

## 核心目标

**把安全无人机云平台从 Vue3 Web 迁移到 React Native 跨平台（iOS + 移动端），同时推进两个产品的 PRD 细化**

### 关键约束
- A 维度（真机测试）随时插队，有板子就停下其他事去测
- 学习不是独立轨道，必须服务当前工作：RN 学习→迁移，产品设计→PRD
- 两个产品并行规划：安全无人机（已有雏形）+ Shadow Device（从零开始）
