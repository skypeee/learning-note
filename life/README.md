# 人生数据集

> "用分析数据的方式分析自己。"
>
> 记录想法、心情、决策、顿悟——不是为了写日记，
> 是为了在三个月、一年后回头看：**我到底是个什么样的人，我适合什么。**

## 用法

| 你说 | AI 做什么 |
|------|-----------|
| "记一下：今天……" | 写入当天 entry |
| "今天心情……" | 追加到当天 entry |
| "分析一下我" | 读取所有 entries，输出性格/方向/发展建议 |
| "回顾一下上个月" | 按月汇总关键模式和变化 |

## 标签约定

每条记录可以用标签分类：
- `#思考` — 对某件事的认知
- `#情绪` — 心情/状态
- `#决策` — 做了一个选择
- `#顿悟` — 突然想明白什么
- `#焦虑` — 压力/担忧
- `#满足` — 成就感/正反馈
- `#人际` — 和人有关的事
